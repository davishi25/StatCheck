# StatCheck
StatCheck is a simple stat checking mod for Hypixel.
## Usage
```/sc <username> <gamemode>```\
currently supports bedwars, bridge, and duels
---
## API
go to https://dev.hypixel.net and generate an api key\
set your api key with ```/api set <key>```
